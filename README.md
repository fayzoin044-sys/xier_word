# 中文 NLP 模型项目合集

本仓库包含两个相互独立的中文自然语言处理项目。每个项目均拥有自己的源码、依赖说明和使用文档。

## 项目目录

| 项目 | 内容 |
| --- | --- |
| [GLM-4-9B LoRA 客服策略微调](glm-lora-customer-service/README.md) | 客服策略分类与回复生成，包含 LoRA 训练、推理、评估和最佳适配器 |
| [多模型中文新闻分类](news-classification-suite/README.md) | 10 类中文新闻分类，包含随机森林、FastText、BERT、Qwen 全量微调和 Flask API |

公开版本已移除原始数据、内部注释、项目笔记、运行日志、本地路径和敏感信息。
