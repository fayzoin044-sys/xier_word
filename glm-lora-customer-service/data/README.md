# 数据说明

数据由中文多轮客服场景的构造对话组成，不包含真实客户信息。仓库保留训练时使用的原始文本，没有对模拟手机号、邮箱、订单号等内容进行二次替换。

## 数据划分

| 文件 | 样本数 | 用途 |
| --- | ---: | --- |
| `train.jsonl` | 30,000 | 12 类均衡训练集，每类 2,500 条 |
| `dev.jsonl` | 1,000 | 训练过程中的验证与模型选择 |
| `test.jsonl` | 4,380 | 独立测试集 |

清洗数据池共包含 160,512 条样本，按完整会话划分后，训练、验证和测试集合之间的会话重叠数均为 0。训练发布集从清洗池中进行分层与重采样得到。

## 标签体系

1. 策略1 礼貌问候
2. 策略2 确认身份
3. 策略3 重述或转述
4. 策略4 细化问题
5. 策略5 情感管理
6. 策略6 提供建议
7. 策略7 信息传达
8. 策略8 解决实施
9. 策略9 反馈请求
10. 策略10 关系延续
11. 策略11 感谢与告别
12. 策略12 其它

## JSONL 格式

```json
{"conversation_id":"train_000001","target_strategy":"策略6 提供建议","prompt":[{"role":"system","content":"任务说明"},{"role":"user","content":"用户消息"}],"completion":[{"role":"assistant","content":"{\"strategy\":\"策略6 提供建议\",\"response\":\"回复内容\"}"}]}
```

每行是一条独立训练样本。`prompt` 保存系统指令和完整对话历史，`completion` 只保存当前目标回复。
